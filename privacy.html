Privacy policy

SENTINEL is a browser security auditing tool. The public web scanner runs checks in the current page and does not send scan findings to a database.

Managed extension data

The managed Chrome/Edge extension can process browser history metrics, bookmark metrics, cookie security attributes, open-tab counts, downloads, installed-extension metadata, privacy settings, and coarse device posture. This data is processed locally on the device for the user-facing audit.

  • No raw passwords or credential material are collected.
  • Raw URLs, cookie names, and cookie values are not included in exported reports.
  • The extension makes no network requests for audit data.
  • Reports are not persisted by the extension; JSON export happens only after the user selects export.
  • The optional native host reports coarse operating-system posture and does not read browser profile databases.
  • SENTINEL does not sell data, serve advertising, or allow human browsing of user data.

Permission use

Permissions are used only to perform the local browser posture audit described in the extension interface and Chrome Web Store listing. The extension does not delete browsing data or change browser settings.

Contact

For questions or security reports, use the project repository: github.com/simiyu-samuel/browser-security-scanner.

This policy may be updated when the extension’s data practices change. Material changes will be disclosed in the extension and listing.
